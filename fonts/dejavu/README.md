# DejaVu Sans 2.37

`DejaVuSans.ttf` is the unmodified regular text font from the DejaVu Fonts 2.37
release: <https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37>.
It provides readable city names, punctuation, and equal-advance clock digits.

See `LICENSE.txt` for the font's license and attribution. The project's BSD
license does not replace the font's license.
